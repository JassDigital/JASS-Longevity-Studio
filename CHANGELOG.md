# Changelog

## v1.0.0 — Complete Local-First Edition

- Reworked the workspace into a complete multi-module healthy-ageing application.
- Added research library search, categories, source details, JSON import and CSV/JSON export.
- Added goals, daily habits, journal entries and wellbeing observations.
- Added nutrition, movement, sleep, and brain/social-connection workspaces.
- Added personal progress summaries and descriptive activity trends.
- Added local research-library retrieval assistant with source excerpts and explicit limitations.
- Added full personal-data JSON backup and database backup utility.
- Added additive SQLite migrations for databases created by v0.1.x.
- Added local system-font fallbacks and accessibility text-size controls.
- Added security, privacy, data dictionary and user documentation.

## v0.1.1 — Dashboard Stabilisation

- Added profile, settings, category filters, theme and text-size preferences.
- Added health endpoint, FTS synchronization and source-level smoke tests.

## v0.1.0 — Foundation

- Initial dashboard, SQLite research library and habit persistence.
